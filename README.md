# Katapult ERP / CRM - Marketing Studio

Moderno SaaS CRM y ERP para gestión comercial, pipeline de oportunidades, contactos, cuentas y analíticas.

## 🚀 Características
- **Dark Navy Sidebar**: Branding Katapult con enlaces de navegación interactivos.
- **Header con Búsqueda Global**: Atajos para notificaciones, calendario, apps y perfil de usuario.
- **Métricas KPI**: Contactos (428), Cuentas (96), Oportunidades (32), Ventas cerradas MTD ($248,500).
- **Kanban Board de Oportunidades**: 5 etapas comerciales (*Prospección*, *Calificación*, *Propuesta*, *Negociación*, *Cerradas*) con cálculo dinámico de montos por etapa y modal para mover tratos.
- **Próximas Actividades**: Llamadas, reuniones, demos y cierres agendados.
- **Contactos Recientes**: Fichas con avatar y rol comercial.
- **Actividad Reciente**: Bitácora de auditoría en tiempo real.
- **Resumen por Fuente**: Gráfica donut SVG con porcentaje de leads por canal.
- **Optimizador AI**: Sugerencias y automatizaciones comerciales.

## 🛠️ Tecnologías
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Vite 6**
- **Lucide React**

## 💻 Instalación y Desarrollo Local
```bash
npm install
npm run dev
```

## 🌐 Despliegue en Vercel
1. Conecta el repositorio de GitHub: `https://github.com/Opiate-code/katapulterp.git`
2. Configuración en Vercel:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
